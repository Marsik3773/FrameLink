# FrameLink

Камера и микрофон Android для Windows. FrameLink передаёт H.264 по локальной сети или USB и устанавливает системную веб-камеру **FrameLink Camera**.

## Подключение

1. Установите Android APK и установщик Windows. Windows запросит права администратора для регистрации камеры.
2. На телефоне нажмите **Открыть доступ**. Камера включится, когда подключится компьютер.
3. На ПК нажмите на телефон в списке устройств. Для ручного подключения введите IP-адрес и порт с телефона. По умолчанию используется TCP 4747. Поиск использует UDP 47470.
4. Для USB выберите **USB** и разрешите USB-отладку для этого ПК. Нужен `adb` из Android Platform Tools. USB-модем работает в режиме **Wi-Fi** с IP-адресом USB-сети. [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)
5. В приложении для видеосвязи выберите **FrameLink Camera**. FrameLink подаёт в неё видео автоматически.

Пока доступ открыт, подключиться может один клиент локальной сети. Трафик шифруется TLS. На Android трансляция продолжает работать при сворачивании. Закрыть доступ можно в приложении или уведомлении. На Windows кнопка закрытия сворачивает FrameLink в область уведомлений. Чтобы остановить приложение, выберите **Выйти** в меню значка.

## Слои

Добавляйте изображения, GIF, видео, текст и веб-страницы на вкладке **Слои**. Перетаскивайте строки, чтобы менять порядок. Верхняя строка отображается поверх остальных. Камеру можно переместить выше фонового слоя, а затем вырезать фон хромакеем или сегментацией. Положение, размер и непрозрачность задаются для каждой строки. Снимок PNG сохраняет прозрачность композиции.

На вкладке **Камера** доступны настройки телефона. Разрешение, FPS, баланс белого, выдержка, ISO и фокус зависят от модели. На вкладке **Вывод** находятся параметры виртуальной камеры, устройство воспроизведения звука и задержка звука.

## Сборка

**Android** требует JDK 17 и Android SDK 35. В папке `android` запустите `./gradlew assembleDebug lintDebug`. Для подписанной сборки `assembleRelease` задайте `FRAMELINK_KEYSTORE`, `FRAMELINK_STORE_PASSWORD`, `FRAMELINK_KEY_ALIAS` и `FRAMELINK_KEY_PASSWORD`.

**Windows** требует Windows x64, Node.js, CMake и Visual Studio с C++ Desktop Development. Команды выполняются в папке `desktop`.

```powershell
npm ci
npm run vendor
./scripts/build-camera.ps1
npm test
npm run build:win
```

Установщик находится в `desktop/dist`. Лицензии используемых компонентов включены в сборку. [Сторонние компоненты](desktop/assets/THIRD_PARTY.md)
